selected to show complementary Physical Adherence (PA) and Instruction
Alignment (IA) outcomes and are not a separate evaluation split.

| `03_agibot_world_cosmos3.mp4` | AgiBot World | Cosmos3-Nano | 5 | 3 |

the [RoboJudge-Bench dataset](https://huggingface.co/datasets/HuggingFriends/RoboJudge-Bench).
